# Tabela de Preços ABI

Preços de itens de Arena Breakout Infinite, registrados a partir de capturas de tela do jogo. Nenhum dado vem da internet.

## Arquivos

- `index.html`: o site (busca, filtro por categoria, ordenação por preço/data).
- `itens.js`: os dados. Cada item tem `nome`, `categoria`, `preco` (Koen), `atributos` opcionais e `atualizado` (data da foto).

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie estes arquivos.
2. No repositório: **Settings → Pages → Branch: main / (root) → Save**.
3. O site fica em `https://SEU-USUARIO.github.io/NOME-DO-REPO/`.

Para atualizar preços, edite `itens.js` e faça um novo commit.
